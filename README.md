# 透视标尺绘图 · Perspective Ruler

纯前端透视绘图工具：在画布上建立一点 / 两点 / 三点透视标尺，线段与自由笔画吸附到正确方向。
React + TypeScript 管理图层与工程状态，Konva 编辑二维笔画，Three.js 显示可选参考盒，
mathjs 承担齐次坐标的交点 / 连线 / 投影运算，IndexedDB 保存工程，无后端。

## 运行

```bash
npm install
npm run dev       # 开发
npm run build     # 类型检查 + 产物
npm test          # 40 个几何/存储/对齐测试（vitest）
```

## 关键设计决策

### 1. 消失点一律用齐次坐标 `[u, v, w]`

- `w ≠ 0`：有限消失点 `(u/w, v/w)`，**允许远在画布之外**；
- `w = 0`：无穷远消失点（方向），表示该坐标轴平行于画面，绘制与吸附都按**平行线族**处理。

`fromHomogeneous` 对 `w≈0` 一律返回 `null`，代码中不存在「坐标太大就夹到画布边缘」的分支
（见 `src/geometry/homogeneous.ts`、`src/geometry/perspective.ts`）。扇形参考线从画外 VP
向矩形求交弦（`lineThroughRect` 射线式 Liang–Barsky 裁剪），VP 再远线都真正经过它。

所有共点 / 平行用同一条齐次判据检验：段直线 `l = cross(p, q)` 与 VP 的点积 `l·VP ≈ 0`
——有限 VP 是汇聚共点，`w=0` 时自动退化为方向平行，无需两套代码。

### 2. 相机、视图、导出裁剪三者彻底分离

| 概念 | 数据 | 改变它会影响什么 |
| --- | --- | --- |
| 相机（focal / yaw / pitch / roll / 像主点） | `Project.camera` | 只影响标尺几何与参考盒 |
| 视图（缩放 / 平移） | `ViewTransform`（不入工程） | 只影响屏幕查看 |
| 导出裁剪框 | `Project.crop` | 只影响画稿导出范围 |

改任何一项都不触碰另两项，也不修改已画笔画（有测试锁定）。

### 3. 笔画双版本：原始与约束都保存

`Stroke.rawPoints`（原始输入，永不修改）与 `Stroke.constrainedPoints` / `snappedAxis`
（约束版本）同时入 IndexedDB。关闭吸附只是渲染 raw，约束数据保留；面板提供
「按当前标尺重新吸附所有笔画」，相机改完后可从 raw 重算（吸附不到就只清约束、不动 raw）。

### 4. 相机模型与约定

世界轴在相机系（x 右、y 下、z 前）下的方向由 `cameraBasis` 给出（旋转矩阵的行）：

- `yaw=0`：X 轴平行画面 → X 消失点在无穷远（一点透视）；`yaw` 增大时 X VP 从极远处进入画面；
- `pitch>0` 俯视 → **高位地平线**（`y_h = py − f·tan(pitch)`，y 向下），竖直 VP 在画面下方远处；
- 无穷远情形（`dz≈0`）投影函数直接返回 `w=0` 的纯方向，绝不做除法。

Three.js 参考盒在相机系围绕固定中心构造，盒棱方向复用同一个 `cameraBasis`，滚转通过
反向旋转场景实现；测试验证 12 条盒棱的屏幕直线（含非居中像主点、滚转俯仰、极远 VP）
与 2D 消失点齐次共点 / 平行。

### 5. 导出分层

- 「导出画稿 PNG」：只渲染画稿图层与笔画，范围取裁剪框或整幅文档；
- 「导出标尺 PNG」：独立文件，范围自动包含画外的有限消失点（无穷远 VP 不参与包围盒，
  只画方向箭头并标 `∞`，不造假点）；
- 「导出工程 JSON」：完整文档 + 几何校验结果。

视觉上标尺与画稿叠在一起不是几何正确性的证据 —— 侧栏「几何校验」与测试套件
（`tests/`）用齐次点积做定量检验。

## 目录

```
src/
  geometry/
    homogeneous.ts   # mathjs 叉积/点积封装、齐次↔欧氏、矩形裁剪
    perspective.ts   # 相机基、消失点投影、地平线、扇形参考线
    snapping.ts      # 方向阈值匹配、投影约束（有限/无穷远同公式）
    verify.ts        # 笔画共点校验、退化检测、导出包围盒
  storage/           # IndexedDB 封装与工程工厂
  export/render.ts   # 画稿/标尺分层渲染与下载
  three/ReferenceBox.ts
  components/        # Konva 舞台、面板、工具栏、参考盒叠加
  store.tsx          # reducer：相机/视图/裁剪/笔画/图层
tests/               # vitest：几何、吸附、退化输入、IndexedDB、3D 对齐、重吸附
```

## 已验证的边界场景

- 高位地平线（俯视 30°，解析位置与齐次结果一致）；
- 极端透视：yaw 0.1° 时 VP 在数千像素外，0.01° 吸附仍稳定；广角 170° / 长焦 5°；
- 退化共线 / 重合 / NaN 输入不抛异常、不产生错误吸附；
- 一点透视中两个无穷远轴的扇形线严格水平 / 竖直；
- 滚转 + 俯仰时地平线是斜线（没有「水平线 = 常数 y」特判）。
